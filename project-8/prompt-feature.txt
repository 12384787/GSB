仓库：embassy-rs/embassy（Rust）。项目原本是：Modern embedded framework, using Rust and async.。当前源码入口可从 .gitattributes, .github, .gitignore, .helix, .vscode, API-GUIDELINES.md, CONTRIBUTING.md, LICENSE-APACHE, LICENSE-CC-BY-SA, LICENSE-MIT, NOTICE.md, README.md 进入。
为 Embassy executor 增加可组合的任务预算与超时诊断能力，要求不依赖分配器，并兼容现有 time、interrupt 和 embassy-sync 原语。设计任务取消、嵌套超时、低功耗唤醒、优先级反转检测及日志开关，补充 host 模拟器和至少一种真实 HAL 的测试，证明 API 和二进制体积没有无谓回归。
